Release history

LATEST CORRECTIONS
1.0.32026-10-08

More precise scans. Reports you can share.

  • Small controls inside overflow containers remain measurable instead of being silently excluded. Completely clipped off-canvas content is excluded.
  • New vertical text-clipping checks catch wrapped text cut off by fixed heights; explicit ellipsis and line clamping are treated separately.
  • Per-device DOM counts make scan coverage visible. Failed frames and scans limited to 5,000 elements are clearly marked.
  • Export JSON or a standalone HTML report, including zero-finding scans. HTML reports include scope, filters and failures and can be printed to PDF.
  • Updated website version, multilingual changelog and English/Turkish walkthrough videos. Norwegian uses the English video.
1.0.32026-10-08

CastPost opens reliably. Scrolling follows faster.

  • Preview loading waits for framing rules and removal of the selected site’s existing worker registration. This can affect that site’s normal tabs; cookies and login storage are retained.
  • Validated real CastPost with an existing worker in Chromium and Firefox, workspace reopening and a Chromium restart.
  • Direct scroll relay avoids the background round trip and overrides smooth scrolling on receiving previews. Exact simultaneous painting is not guaranteed.
  • Extension version and source build ID are visible inside the workspace.
1.0.32026-10-08

Firefox compatibility and preview protection.

  • Firefox background compatibility and prevention of worker re-registration in verified previews.
1.0.22026-10-08

A more dependable workspace.

  • Preview isolation, reload synchronization and complete device captures. Grouped findings with measurements, filters and copy/export tools.
1.0.12026-09-24

Framing and permissions improvements.

  • Earlier service-worker and redirect handling fixes, persistent workspace state, source packages and host-permission guidance. Later 1.0.3 corrections refine worker cleanup and preview scoping.
1.0.02026-09-21

The first ViewGrid workspace.

  • Multi-viewport layouts, device presets, synchronized interaction, comparison tools and local responsive checks.
