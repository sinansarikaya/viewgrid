# Tarihsel harici analiz UI testleri

Bu dizindeki iki E2E dosyası önceki Google PageSpeed onayı ve üç turlu uzak ölçüm arayüzüne aittir. 1.0.4 yerel motorunda bu akış bulunmadığından varsayılan Playwright test dizininden çıkarıldı. Tarihsel kaynak korunur; mevcut ürün testleri `tests/e2e/local-analysis.spec.ts`, `firefox_local_analysis.py`, güncellenen `extension.spec.ts` ve `interaction-fixes.spec.ts` içindedir. Legacy PSI normalizasyon/rapor/geçmiş birim testleri çalışmaya devam eder.
