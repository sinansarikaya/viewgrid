# ViewGrid 1.0.3

Fixes the Chrome protected-preview navigation/reload regression and the Firefox framing failure.

- Chromium framing rules now cover page-initiated navigation and reload within verified workspace tabs, including nested frames. Normal browsing tabs remain protected.
- Firefox uses Manifest V2 because Firefox MV3 cannot relax XFO/CSP. Only direct workspace previews receive XFO/frame-ancestors exceptions; other CSP directives and cookies are retained.
- Chromium previews disable worker registration after workspace verification to prevent worker responses bypassing framing rules. No browser-wide worker/cache cleanup is used.
- Both browser manifests use the package version; packaging rejects stale dist builds.
- Ready-to-load dist/chromium and dist/firefox builds are included in the repository and source ZIP.
- Real Chromium and Firefox extension regression tests cover protected navigation/reload, ordinary-tab protection, preview worker isolation and CastPost. Chromium also covers Issues export, screenshots and synchronization.

## Test installation

Remove the old unpacked/temporary extension before loading the new build, then open a new ViewGrid workspace.

- Chrome: extract viewgrid-1.0.3-chromium.zip; chrome://extensions → Developer mode → Load unpacked → extracted folder containing manifest.json.
- Firefox: extract viewgrid-1.0.3-firefox.zip; about:debugging#/runtime/this-firefox → Load Temporary Add-on → manifest.json.
- Source checkout/archive: use dist/chromium for Chrome or dist/firefox/manifest.json for Firefox, not the parent dist folder.

Verify version 1.0.3 in the extension details. Firefox temporary installs disappear after restart. Store submissions and signed AMO installation are separate from this GitHub release.

Cached/synthetic service-worker responses, third-party cookie restrictions and some authentication flows can still prevent iframe previews. Chromium defers worker registration until the preview agent verifies its workspace tab, then disables registration and unregisters workers visible in that preview storage partition. Existing controlled previews reload once after unregistering. Normal tabs are untouched; cookies, localStorage, sessionStorage and CacheStorage are retained. Device profiles do not emulate a mobile browser engine or hardware DPR.
