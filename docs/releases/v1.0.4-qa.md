# 1.0.4 doğrulama

Gerçek masaüstünde görünür Chromium/Firefox akışları ve362 unit test geçti. Hassas alan, aynı-origin, frame/document bağlama, worker yeniden başlatma kontrolleri bağımsız kaynak incelemesinde kapandı. CastPost görselleri1280×800 boyutlarında gerçek https://castpost.app/en üzerinden alındı. Yerel tam E2E çalışmasında build sırasında yeniden yükleme testi asset yenilenmesine rastladı; build bittikten sonra aynı test geçti.

Hosted CI gerçek kullanıcı masaüstü sunmadığından native tarayıcı adımları self-hosted ortama koşulludur. Atlanan adımlar başarılı native QA diye sayılmaz; birim/type/lint/build/paket kontrolleri hosted CI'da çalışır. Yerel GUI kanıtı test-results/release-readiness altında tutulur. Tam WCAG veya mağaza kabulü garantisi yoktur.
