### Why These Topics?
1. **`browser-extension` / `chrome-extension` / `firefox-extension`**: Captures developers looking specifically for in-browser extensions rather than heavy Electron desktop apps.
2. **`responsive-design` / `responsive-testing` / `responsive-design-tools`**: Core search terms used by frontend developers when searching GitHub for viewport testing solutions.
3. **`developer-tools` / `web-development` / `frontend`**: High-level developer taxonomy that places ViewGrid in GitHub Explore and trending lists.
4. **`manifest-v3` / `typescript`**: Highlights modern WebExtension architecture and clean open-source TypeScript codebase.

## 🚀 Social Preview Card (Open Graph Image)

Under repository **Settings → General → Social preview**:
- Recommended image: `website/public/screenshots/workspace.png` (or a dedicated 1280×640 PNG composite of the multi-viewport workspace).
- Shows real UI instead of an empty repository avatar when shared on GitHub, X, LinkedIn, or Discord.
